# 📊 E-Commerce Sales SQL Analysis

A SQL-based business analytics project built using the **Superstore_Dataset** retail dataset. The project analyzes nearly **10,000 customer transactions** to generate business insights related to sales, profit, customers, products, regions, and discounts using MySQL.

---

## Project Overview

This project demonstrates how SQL can be used to perform exploratory data analysis and business reporting on an e-commerce sales dataset. The analysis focuses on identifying trends, customer segments, profitable regions, and product performance through SQL queries.

---

## Dataset Information

* **Dataset:** Sample Superstore
* **Total Records:** 9,994 Transactions
* **Database:** MySQL
* **Domain:** Retail / E-Commerce Sales

* Top Customers by Revenue
* Top Products by Revenue
* Top States by Profit
* Quantity Sold by Sub-Category
* Average Discount by Category

---

## Key Business Insights

* Regional sales comparison identifies the highest revenue-generating regions.
* Customer segment analysis helps understand revenue contribution from different customer groups.
* Product performance analysis identifies best-selling products and profitable categories.
* Profit and discount analysis supports better pricing and business decisions.
